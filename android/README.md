# الفهد TV

مشروع مستقل بالكامل عن تطبيق EasyPlex القديم.

## المكونات

- `app`: تطبيق Android WebView آمن بحزمة `com.alfahdtv.app`.
- `backend`: خدمة مستقلة لإعدادات التطبيق والتحديثات، جاهزة للنشر على Railway.

## الأمان

- السماح بالتصفح داخل نطاق الموقع الرسمي فقط.
- حظر HTTP وشهادات SSL غير الصالحة والوصول للملفات المحلية.
- لا توجد JavaScript interfaces ولا أسرار مخزنة داخل التطبيق.
- تعطيل النسخ الاحتياطي ولقطات الشاشة في إصدار Release.
- تصغير وتشويش الكود في إصدار Release عبر R8.

## البناء

يحتاج JDK 11 وAndroid SDK 34. شغّل `gradlew assembleDebug` أو افتح المجلد في Android Studio.
